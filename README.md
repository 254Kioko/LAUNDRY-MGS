# LAUNDRY-MGS

## Project Overview
**LAUNDRY-MGS** is a modern laundry management system designed to streamline operations for small to medium-sized laundry businesses. The application allows users to manage orders, track customer requests, and automate notifications efficiently. The goal of this project is to reduce manual workload and improve service delivery.

## Problem Solved
Laundry businesses often struggle with manual tracking of orders and customer communication. This project provides a web-based platform that centralizes management, ensuring timely processing and better customer experience.

## Technologies Used
- **Frontend:** React.js with TypeScript, Tailwind CSS, ShadCN UI components  
- **Backend:** Supabase (PostgreSQL database and authentication)  
- **Build Tools:** Vite  
- **Other Tools:** Node.js, Bun for package management
